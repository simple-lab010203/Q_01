# 정치존잼 모션 쇼츠

정치존잼 유튜브 쇼츠용 세로 모션그래픽을 HyperFrames로 만든다. 렌더링 워크플로(HTML 작성, 린트, 미리보기, 렌더)는 `/hyperframes:hyperframes` 스킬을 따르고, 디자인과 연출은 아래 규칙을 따른다. 답변과 안내는 한국어로 한다.

## 공용 소재 (고정 경로)
- 키트 폴더: `D:\motion\_jzj-kit\`
  - `mungi*.png` : 먼지 캐릭터 (투명 PNG, 여러 포즈 가능)
  - 이름에 '로고' 또는 'logo'가 들어간 파일 : 정치존잼 채널 로고
  - `KyoboHandwriting2025lyb.*` : 기본 폰트
  - `bgm\` : 배경음악 후보
- 새 작업은 `D:\motion\<YYMMDD>_<주제>\` 폴더를 만들고 키트 소재를 그 안 `assets\`로 복사해서 쓴다. 키트 폴더의 원본은 수정하지 않는다.
- bgm 폴더에 곡이 여러 개면 목록을 보여주고 어떤 곡을 쓸지 먼저 물어본다.

## 기본 사양
- 1080x1920 세로, 30fps, MP4.
- 길이는 **1분 이내**에서 내용에 맞게. 30초에 억지로 맞추지 않는다(30초짜리가 너무 빠르다는 피드백이 있었음). 시청자가 읽고 이해하고 넘어갈 속도로: 화면 문구 하나당 최소 2.5초.
- 정렬은 화면 중심(x=540) 기준. 오른쪽 12% 안전영역을 피한다고 글자 영역을 왼쪽에 붙이지 말고, 가운데를 기준으로 폭을 줄인다(예: 글자 영역 left 130px, 폭 820px).
- 숫자·날짜처럼 나중에 바뀔 값은 HTML 맨 위 변수 하나로 관리하고, 끝나면 바꾸는 방법을 한 줄로 알려준다.
- 쇼츠 UI 안전영역: 하단 20%와 오른쪽 끝 12%에는 글자·버튼·로고를 두지 않는다.

## 디자인 톤
- 배경: 흰색(#FFFFFF)에 아주 연한 하늘색 도트 그리드가 천천히 흐름
- 글씨: 진한 남색(#1B2A6B)
- 강조: 형광 옐로우그린(#C8FF3D) 형광펜 하이라이트. 글자 뒤 둥근 박스가 왼쪽에서 오른쪽으로 칠해지는 애니메이션. 한 장면에 강조는 한 덩어리만.
- 보조 박스: 연한 하늘색(#E3F2FF), 모서리 둥글게, 화면 폭 85%
- 폰트: KyoboHandwriting2025lyb 를 @font-face로 등록해 모든 글자에 사용. 손글씨라 획이 얇으므로 모든 글자에 흰색 외곽선 6px + 연한 그림자.

## 글자 크기 (폰 화면 기준 최소값 — 이보다 작게 하지 않는다)
- 메인 자막: 한 줄이 화면 폭의 75~85% (대략 110~130px). 두 줄 자막은 두 줄 모두 같은 크기.
- 큰 숫자(카운터 등): 화면 폭의 70% 이상
- 보조 문구("댓글로 알려주세요", 라벨 등): 60~64px
- 말풍선 글자: 72px, 말풍선도 비례해서
- 핸들 "@thepoliticsjam": 48px
- 버튼: 화면 폭 40%, 글자 56px. 상태가 바뀌는 버튼(구독 → 구독중)은 바뀌기 전후 크기를 똑같이.
- 너무 작아서 장식처럼 보이는 글자는 넣지 말고 아예 뺀다.

## 레이아웃
- 자막은 세로 25~50% 구간, 먼지는 세로 55~78% 구간(중앙~오른쪽)에 둬서 화면 위아래를 채운다. 화면 절반이 비는 장면이 없게.
- 마지막 장면은 위에서부터: 질문/메시지 → 보조 문구 → 버튼 → 먼지 → 로고 → 핸들. 서로 겹치지 않게 세로로 쌓는다.

## 먼지 캐릭터
- **수치·데이터·지표처럼 객관적 정보를 다루는 영상에는 먼지를 넣지 않는다.** 차트와 글자만으로 구성한다. 먼지는 축하·공지·가벼운 설명 영상에만 쓴다.
- 반드시 키트의 PNG를 그대로 쓴다. 다시 그리거나 색·모양·비율을 바꾸지 않는다.
- 크기: 화면 폭의 30~33% (영상의 주인공)
- 움직임은 위치·크기·회전·통통 튀기(squash & stretch)만으로 표현: 아래에서 쏙 등장, 깡충 점프, 끄덕끄덕, 좌우로 기울며 손 흔들기.
- 리액션은 연한 하늘색 말풍선 한 줄로.

## 두 가지 버전 (항상 둘 다 만든다)
- **로고 버전 (유튜브용)**: 마지막 장면 = 질문/메시지 → 보조 문구 → 구독 버튼 → 로고 → 바로 아래 핸들 → (데이터 영상이면) 출처.
- **핸들 버전 (X·트친용)**: 구독 버튼과 로고를 넣지 않는다. 질문/메시지 → 보조 문구 → 핸들 → (데이터 영상이면) 출처. 빠진 만큼 요소들을 화면 세로 가운데로 내려 아래가 비지 않게 한다. 버튼 '딸깍' 효과음도 뺀다.
- HTML 맨 위 변수 하나(예: `ending: "logo" | "handle"`)로 구분하고, 두 버전을 한 번에 렌더하는 스크립트를 함께 둔다.

## 수치·데이터 영상
- 숫자는 만들기 전에 원자료(공식 발표·보고서)와 대조해 확정한다.
- 차트 장면에 출처를 표시하고, 마지막 장면에도 핸들 아래에 출처(예: "출처 · WIPO 글로벌 혁신지수")를 넣는다.
- 해마다 바뀌는 순위·지표는 화면에 기준 연도("2026년 기준")를 밝힌다.
- 특정 정부·정치인의 성과로 단정하지 않고 숫자 흐름만 보여준다. "다음 목표는 3위?"처럼 질문형은 괜찮지만 공식 목표처럼 쓰지 않는다.

## 로고
- 정치존잼 로고는 마지막 장면에서 @thepoliticsjam 핸들이 나올 때만 함께 등장한다. 영상 중간이나 코너에 상시로 띄우지 않는다.
- 핸들 바로 위, 화면 폭 45%, 스케일 0.8→1.0 + 페이드인.
- 로고 색·비율·모양은 바꾸지 않는다.

## 모션 규칙
- 자막은 장면마다 아래에서 살짝 올라오며 0.3초 페이드인, 다음 장면 전 페이드아웃
- 장면 전환은 0.2초 화이트 와이프 또는 스케일 전환
- 템포는 경쾌하되 급하지 않게(문구 하나당 최소 2.5초). 화면에서 아무것도 안 움직이는 순간이 0.5초를 넘지 않게 — 글자가 머무는 동안에도 배경 도트, 살짝 커지는 박스 등 작은 움직임을 둔다.
- 큰 순간(숫자 달성, 핵심 발표)에는 줌 펀치 + 형광 연두·하늘색 컨페티

## 소리
- 배경음악을 처음부터 끝까지 깔고, 효과음보다 작게, 마지막 1초 페이드아웃
- 효과음은 FFmpeg로 합성: 숫자 넘어갈 때 '틱', 큰 순간 '팡', 하이라이트 칠할 때 '슥', 버튼 '딸깍', 장면 전환 '뿅'
- 무음 구간이 1초를 넘지 않게
- 최종 MP4 음량은 쇼츠 기준 약 -14 LUFS(최고 -1.5 dBFS)로 맞춘다. BGM은 효과음보다 작게(BGM 단독 약 -22 LUFS).

## 마무리 검수 (렌더링 후 반드시)
- 장면마다 프레임 1장씩 캡처해서 직접 확인한다.
- 확인 항목: 글자 잘림, 먼지·로고·버튼과 글자 겹침, 안전영역 침범, 위 글자 크기 최소값 미달, 화면 절반이 비는 장면, 버튼 상태 전후 크기 차이
- 문제가 있으면 고치고 다시 렌더링한 뒤, 무엇을 고쳤는지 짧게 알려준다.

## 톤 원칙
- 정치존잼은 쉽고 짧게, 중립적으로. 상대 진영 멸칭이나 공격적 표현은 쓰지 않는다.
- 다른 채널(다른 브랜드)과 연결되는 요소나 언급은 넣지 않는다.

## 참고: 첫 작품
- `D:\motion\jzj-1000\` 의 "구독자 1,000명 감사" 영상(18초)이 이 스타일의 기준이다. 구성: 997→999 카운터 + 먼지 "어...?" → 1,000명 달성 컨페티 → 감사 인사 → 채널 소개 → 앞으로의 약속 → "언제부터 보셨어요?" + 구독 버튼 + 로고·핸들.
- 다음 축하 영상(5천, 1만 명 등)은 이 구성을 그대로 쓰고 숫자 변수와 문구만 바꾼다.
